# dhls

Shopping cart starter built with Next.js, TypeScript, Tailwind CSS, Supabase, Stripe, GitHub Actions, and Vercel.

## Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS
- Supabase Auth, Postgres, Storage
- Stripe Checkout
- GitHub Actions CI
- Vercel deployment

## Getting started

1. Copy `.env.example` to `.env.local`.
2. Fill in your Supabase and Stripe values.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Run the development server:
   ```bash
   npm run dev
   ```
5. Visit `http://localhost:3000`.

## Environment variables

- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`
- `SUPABASE_SERVICE_ROLE_KEY`
- `STRIPE_SECRET_KEY`
- `NEXT_PUBLIC_APP_URL` (optional)

## Deployment

- Push the branch to GitHub and the workflow in `.github/workflows/ci.yml` will run on pushes and pull requests.
- Deploy to Vercel and configure the same environment variables in your Vercel project settings.

## Supabase storage and product catalog

1. Create a public bucket for product images:
   ```bash
   supabase storage create-bucket product-images --public
   ```
2. Create a `products` table in Supabase:
   ```sql
   create table products (
     id bigint generated by default as identity primary key,
     name text not null,
     description text,
     price int not null,
     image_path text
   );
   ```
3. Add sample products:
   ```sql
   insert into products (name, description, price, image_path) values
     ('DHLS Starter Tee', 'A demo product for the DHLS storefront.', 2999, 'products/starter-tee.png'),
     ('DHLS Tote Bag', 'Everyday carry with a Supabase-powered catalog.', 1999, 'products/tote-bag.png');
   ```
4. Upload images to the `product-images` bucket with the same paths assigned in `image_path`.

## Product management

- Visit `/admin/products` to create, edit, and delete product records.
- Use the storage uploader on the admin page to upload product images into the `product-images` bucket.
- Product checkout is wired to actual catalog items using `/api/checkout`.

## Notes

- `src/components/AuthForm.tsx` handles Supabase sign-in.
- `src/components/StorageUploader.tsx` uploads files to Supabase Storage.
- `src/lib/supabase-admin.ts` creates a server-only Supabase client with the Service Role key.
- `src/lib/products.ts` loads catalog data from the `products` table.
- `src/lib/supabase-storage.ts` resolves public image URLs from the `product-images` bucket.
- `src/app/api/checkout/route.ts` creates Stripe Checkout sessions.
